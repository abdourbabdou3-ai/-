# 💎 الماسة - متجر الإكسسوارات النسائية الفاخرة

متجر إلكتروني متخصص في بيع المجوهرات والإكسسوارات النسائية الفاخرة بتصميم عصري وأنيق.

## ✨ الميزات المكتملة

### 🎨 التصميم والواجهة
- ✅ تصميم عصري فاخر بألوان الذهبي والأسود
- ✅ واجهة مستخدم عربية كاملة (RTL)
- ✅ تصميم متجاوب يعمل على جميع الأجهزة
- ✅ تأثيرات ثلاثية الأبعاد احترافية
- ✅ أنيميشن سلس وجذاب

### 🛍️ عرض المنتجات
- ✅ **كاروسيل ثلاثي الأبعاد للمنتجات المميزة**
  - دوران تلقائي كل 5 ثوانٍ
  - إيقاف التدوير عند التمرير بالماوس
  - أزرار تنقل احترافية بتأثيرات ذهبية
  - نقاط تنقل تفاعلية
  - حساب ديناميكي للزاوية حسب عدد المنتجات
  - توسيط مثالي للعناصر
- ✅ شبكة منتجات قابلة للتصفية
- ✅ صور عالية الجودة مع تكبير تفاعلي (Zoom)
- ✅ نظام تقييم بالنجوم (5 نجوم)
- ✅ عرض السعر بالدينار الجزائري

### 🔍 نظام البحث المتقدم
- ✅ **مربع بحث منبثق احترافي**
  - بحث فوري أثناء الكتابة
  - البحث في اسم المنتج والفئة والوصف
  - عرض النتائج مع الصور والأسعار والتقييمات
  - إمكانية الانتقال المباشر للمنتج
  - إغلاق تلقائي عند النقر خارج المربع

### 🎯 نظام الفلترة الذكي
- ✅ فلترة حسب الفئة (خواتم، أساور، عقود، حلق، خواتم خطوبة)
- ✅ فلترة حسب اللون (ذهبي، فضي، ذهبي وردي، أسود، أبيض)
- ✅ فلترة حسب نطاق السعر
- ✅ فلترة حسب التقييم
- ✅ زر إعادة تعيين الفلاتر

### 💝 ميزات التفاعل
- ✅ نظام المفضلة (Favorites)
- ✅ نظام السلة (Cart)
- ✅ إشعارات منبثقة للعمليات
- ✅ حفظ البيانات في LocalStorage

### 📱 التنقل والأقسام
- ✅ قائمة تنقل ثابتة في الأعلى
- ✅ **روابط التنقل تعمل بشكل صحيح:**
  - الرئيسية

  - اتصل بنا

## 🔧 التقنيات المستخدمة

### Frontend
- **HTML5** - بنية صفحة دلالية
- **CSS3** - تصميم متقدم مع:
  - CSS Grid & Flexbox
  - CSS Transforms 3D
  - CSS Animations
  - Backdrop Filters
  - Custom Properties (CSS Variables)
- **JavaScript (Vanilla)** - برمجة تفاعلية مع:
  - Fetch API للتواصل مع قاعدة البيانات
  - LocalStorage للحفظ المحلي
  - DOM Manipulation
  - Event Handling
  - Async/Await

### المكتبات الخارجية (CDN)
- **Font Awesome 6.4.0** - الأيقونات
- **Google Fonts** - خطوط Cairo و Playfair Display

### قاعدة البيانات
- **RESTful Table API** - للتعامل مع البيانات:
  - GET: استرجاع المنتجات
  - POST: إضافة منتجات جديدة
  - PUT/PATCH: تحديث المنتجات
  - DELETE: حذف المنتجات

## 🚀 المسارات الوظيفية

### الصفحة الرئيسية
- **المسار:** `index.html`
- **الأقسام:**
  - `#home` - القسم الرئيسي
  - `#products` - قسم الفلترة والمنتجات
  - `#categories` - قسم الفئات
  - `#about` - قسم من نحن
  - `#contact` - قسم اتصل بنا

### نقاط النهاية API
- `GET tables/products` - جلب جميع المنتجات
- `GET tables/products?is_featured=true` - جلب المنتجات المميزة
- `POST tables/products` - إضافة منتج جديد
- `PUT tables/products/{id}` - تحديث منتج
- `DELETE tables/products/{id}` - حذف منتج
